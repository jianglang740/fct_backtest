# 单因子回测框架（改进版）说明

> 本文档介绍 [code/fct_backtest改进版.py](../code/fct_backtest改进版.py) 相对原版
> [code/fct_backtest注释版.py](../code/fct_backtest注释版.py) 的四大改进、新增指标与使用方法。
> 改进的出发点见 [框架改进方向.md](../框架改进方向.md)；数据增强脚本见 [code/构造市值行业数据.py](../code/构造市值行业数据.py)。

## 一、为什么需要改进版

原版框架在长期使用中暴露了四个问题，分别位于数据输入层、策略执行层、统计推断层与归因逻辑层：

| 问题 | 原版缺陷 | 后果 | 改进版做法 |
| ---- | -------- | ---- | ---------- |
| 一、前视偏差 | MAD 去极值 / Z-score 标准化用**全历史 × 全股票**的全局统计量 | 回测"穿越"使用了未来分布；不适应牛熊市风格漂移，因子跨期不可比 | 先过滤样本池，再按**每日截面**计算统计量（只含当日股票） |
| 二、日频绑定 | `iloc[::period]` 用固定交易日间隔强行模拟持有期 | 月频因子无法适配；调仓日不落自然月边界，与财报披露错位 | 引入**日历化调仓**（auto / weekly / monthly / daily），收益按"调仓窗口"锚定 |
| 三、缺显著性检验 | 只有 Spearman IC，无回归、无自相关修正 | 无法量化"因子每变动 1 单位带来多少收益"；IC 序列自相关导致 t 值虚高 | 新增 **Fama-MacBeth 每日截面回归** + **Newey-West HAC 修正 t 值** |
| 四、缺风格剥离 | 全程未剥离市值 / 行业 | 分层收益混淆了大小盘风格与行业贝塔，无法证明独立 alpha | 逐日对因子做截面回归 `factor ~ log(市值) + 行业哑变量`，取**残差**作为中性化因子 |

> 一句话：原版回答"因子有没有排序能力"，改进版进一步回答"因子有没有**统计显著**、**独立于市值/行业**的预测能力"。

## 四、改进一：每日截面预处理（消除前视偏差）

**原版**：对全量 `price_data` 一次性调用 `extreme_MAD` / `standardize_z`，中位数、MAD、均值、标准差全部来自全历史 × 全股票 → 用未来样本的分布处理早期因子。

**改进版**：先 `preprocess_data` 过滤样本池（去 ST / 次新），再对每个因子列按 `groupby(level='trade_date')` 逐日截面做 MAD 缩尾与 Z-score 标准化，统计量只用**当日可投资股票**，最后 `fillna(0)`（当日截面均值水平）。

```python
for col in factor_names:
    price_data[col] = price_data.groupby(level='trade_date')[col].transform(extreme_MAD)
    price_data[col] = price_data.groupby(level='trade_date')[col].transform(standardize_z)
price_data[factor_names] = price_data[factor_names].fillna(0)
```

先过滤、后算截面统计量，保证统计量只反映可投资池，避免 ST 股污染当日分布。

## 五、改进二：日历化调仓（支持月频/周频因子）

### 5.1 调仓方式（`build_rebalance_dates`）

| `rebalance` | 调仓日 | 适用场景 |
| ----------- | ------ | -------- |
| `auto` | 每隔 `period` 个交易日取一个（非重叠） | 严格复现原版 `iloc[::period]` 行为，便于新旧对照 |
| `daily` | 每个交易日 | 日频因子 |
| `weekly` | 每周最后一个交易日 | 周频因子 |
| `monthly` | 每个自然月最后一个交易日 | **月频 / 财报因子**，调仓日与月度再平衡、财报披露对齐 |

### 5.2 收益的时间轴锚定（窗口制，而非固定日间隔）

对调仓日序列 `R = [r1, r2, …, rn]`：

```
调仓日 r_i 收盘  → 因子值已知（标签贴在 r_i）
r_i 次日收盘     → 模拟"次日买入"价
下一卖出调仓日次日 → 模拟"卖出"价（auto 为下一个 R；其余为 period 个窗口后的 R）
收益率 = 卖出 / 买入 − 1
```

- `auto`：卖出 = 下一个调仓日的次日 → 严格等价原版 `shift(-period-1)/shift(-1)`，行为不变。
- `monthly` + `period=1`：即"月末因子值 → 下月收益"的非重叠**月频**窗口，彻底解决月频因子被日频绑定、调仓日错位的问题。
- `period` 在非 auto 模式下表示**持有的调仓窗口数**（monthly 下 `period=2` = 持有 2 个月），**单位随调仓方式变化**（auto/daily=天、weekly=周、monthly=月）。
- **默认持有期按调仓方式自适应**：`weekly` / `monthly` 默认只测 1 个窗口（持 1 周 / 1 个月），`auto` / `daily` 默认 `(1,5,10,20)` 天；多窗口需显式 `FCT_PERIODS`（如 `FCT_PERIODS=1,3,6,12` 与 monthly 搭配 = 持有 1/3/6/12 个月）。

### 5.3 年化口径

| 调仓方式 | 每个窗口折算交易日 |
| -------- | ------------------ |
| `monthly` | 21 |
| `weekly` | 5 |
| `auto` / `daily` | `period`（天） |

> 重叠窗口（`period>1` 的日历化调仓）下，策略收益序列按 **1 个调仓窗口** 采样（daily=1 / weekly=5 / monthly=21 天），不再按 `period` 折算，避免总天数虚增 `period` 倍导致年化失真。

### 5.4 重叠窗口的绩效口径：重叠加仓重建（关键修复）

`daily / weekly / monthly` + `period>1` 时，相邻持有窗口会**重叠**（如 monthly + `period=12`：每月调仓、持有 12 个月，相邻窗口重叠 11 个月）。若直接把每个调仓日的整段持有期收益连乘（`cumprod`），重叠部分被**重复复利**，会得到天文数字的虚假绩效——早期版本的真实漏洞：实测 `daily + 20 天` 曾算出多空收益 **−844 万%**、`weekly + 16 周` **−55,156%**。

修复后按**真实策略口径**重建绩效（`_overlapping_strategy_returns`）：

- 策略在每个调仓窗口持有最近 `period` 个开仓日选出的**等权组合**（各 `1/period` 权重，全持仓）；
- 窗口 j 的策略收益 = `(1/period)·Σ_{i=j-period+1..j} R[i,j]`，其中 `R[i,j]` = 第 i 个开仓日组合在窗口 j 的等权收益；
- 累计收益 / 多空收益 / 年化 / 夏普 / 最大回撤全部基于这一重建序列，数值回归可解释量级（实测 daily 20 天多空收益约 −0.83、weekly 16 周约 −0.42）；
- **无重叠场景（`auto` 或 `period=1`）不改变任何口径**，结果与旧版逐点一致（period=1 的 IC / FM / 市值相关实测不变）；
- 重叠窗口的收益序列存在 `MA(period-1)` 自相关，Newey-West 滞后阶数取 `max(默认, period-1)`，防止 t 值再次虚高（见 §6.2）。

## 六、改进三：Fama-MacBeth 回归 + Newey-West 检验

### 6.1 Fama-MacBeth 截面回归（`fama_macbeth_regression`）

在每个调仓日做**截面 OLS**：`收益率 ~ 因子值`（可带控制变量），收集全期斜率序列，再取均值即"因子每变动 1 个单位带来的平均收益"：

| 输出 | 含义 |
| ---- | ---- |
| `FM斜率(BP)` | 平均截面斜率 × 10000，以**基点**（BP）表示，直接量化风险溢价 |
| `FM_t_naive` | 斜率均值的普通 t 值（假设独立同分布） |
| `FM_t_NW` | **Newey-West HAC 修正**后的 t 值（修正序列自相关） |

### 6.2 Newey-West 自相关修正（`newey_west_se`）

IC、多空收益、FM 斜率序列存在严重序列自相关，普通 t 值会**虚高**、把噪音因子误判为有效信号。改进版用 Bartlett 权重做 HAC 修正：

```
lag 选择: lags = floor(4 × (n/100)^(2/9))   # n 为样本数
修正方差: γ0 + 2·Σ (1 − k/(lags+1))·γk
```

- 重叠窗口（`period>1` 的日历化调仓）下收益序列具有 `MA(period-1)` 结构，滞后阶数取 **`max(默认, period−1)`**，覆盖重叠长度、防止 t 值再次虚高（修复 §5.4）。
- 纯 numpy 实现，不引入 statsmodels 依赖。

### 6.3 新增显著性指标汇总

| 指标 | 说明 | 含义 |
| ---- | ---- | ---- |
| `IC_t_naive` | IC 均值的普通 t 值 | 修正前显著性 |
| `IC_t_NW` | IC 均值的 **Newey-West t 值** | **修正自相关后的显著性**，主判据 |
| `多空_t_naive` | 多空组合收益序列的普通 t 值 | 修正前显著性 |
| `多空_t_NW` | 多空组合收益序列的 **Newey-West t 值** | 修正自相关后的显著性 |
| `FM斜率(BP)` | 截面回归平均斜率 × 10000 | 因子风险溢价的绝对量级 |
| `FM_t_NW` | FM 斜率的 **Newey-West t 值** | 风险溢价是否显著非零 |

## 七、改进四：市值 + 行业中性化（Barra 风格剥离）

### 7.1 原理（`neutralize_factor`）

在每个调仓日对因子做**截面回归**，取**残差**作为中性化因子（Barra 风格 residualization）：

```
因子 ~ log(总市值) + 行业哑变量
中性化因子 = 因子 − 市值/行业可解释部分（残差）
```

- `mode='mktcap_industry'`：`factor ~ log(mkt_cap) + 行业哑变量`（默认，最严格）
- `mode='mktcap_only'`：只剥离市值
- `mode=None`：关闭中性化

分层（`pd.qcut`）与 FM 回归均基于**中性化后**因子，因此 `中性化IC / FM斜率 / 多空收益` 反映的是剥离市值与行业后因子的**纯 alpha**。

### 7.2 风格诊断

`analyze_factor_performance` 额外计算 **`因子 vs log(市值)` 的日均秩相关**（`mkt_cap_corr`）：

- 接近 0 → 因子与大小盘无关；
- 显著为负 → 因子是小市值"马甲"，分层收益里很大一部分是赚小盘股的钱；
- 中性化后若 IC / 斜率**未明显衰减**，说明因子确有独立的 alpha；若**大幅衰减**，说明收益主要来自风格暴露。

> 实测：默认 `fct_2` 的市值相关约 −0.06（轻微小市值倾向），中性化后 IC 与 FM 斜率不降反升，说明该因子的预测能力独立于市值与行业。

## 十、注意事项

1. **数据区间**：price_data 覆盖 2021-01-04 ~ 2025-11-28；fct_df 至 2025-10-31，合并取交集后以 fct_df 为准。月频调仓的最后一个调仓日若没有后续卖出日会被自动剔除，属正常行为。
2. **中性化降级**：若数据缺失 `mkt_cap` / `industry` 列，脚本会打印醒目警告并把中性化降级为 `None`，不会报错。
3. **回归的最小样本**：单日截面股票数 < 10 时跳过该日 FM 回归；IC 要求当日样本 > 5。
4. **Newey-West 滞后阶数**：`floor(4×(n/100)^(2/9))`，样本量很小时自动收敛到可用上限；重叠窗口（`period>1` 的日历化调仓）时不低于 `period−1`。
5. **仍未解决的限制**（改进版不涉及）：交易成本、涨跌停/停牌不可交易、换手率与调仓成本、组内权重（默认等权）。详见 [该框架的局限性.md](该框架的局限性.md)。
